# Avatar Absent · LaSuite

Génère un avatar « absent » aux couleurs de [LaSuite](https://lasuite.numerique.gouv.fr/) : overlay coloré sur votre photo + icône (vacances, congés, déplacement, parentalité…).

**Accessible ici → [marwann.github.io/lasuite-avatar](https://marwann.github.io/lasuite-avatar/)**

## Fonctionnement

1. Déposez votre photo
2. Choisissez un motif d'absence
3. Ajustez la couleur et l'opacité
4. Téléchargez le PNG 1024×1024

Tout est traité dans le navigateur, aucun fichier n'est envoyé.
